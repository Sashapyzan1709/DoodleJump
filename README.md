# Генератор надёжных паролей

Простой и небезопасный инструмент для создания случайных паролей. Идеально подходит для обучения основам Python и работы с GitHub.

## 🚀 Быстрый запуск
1. Склонируйте репозиторий или скачайте файл `password_generator.py`
2. Откройте терминал в папке с проектом
3. Выполните команду:
   ```bash
   python password_generator.py
   ```
4. Следуйте инструкциям в консоли

## ✨ Возможности

- Генерация паролей длиной от 8 до 32 символов
- Использование букв (верхний и нижний регистр), цифр и спецсимволов
- Защита от ввода некорректной длины пароля

> 💡 Совет: Никогда не используйте один и тот же пароль на разных сайтах!
